🛠️ Ferramentas de TI só você

Manutenção do sistema. Aparece apenas para o e-mail raiz.

1. Diagnóstico do sistema

Testa a leitura de cada coleção (acha problema de regras), mostra o seu acesso e avisa se ainda há senhas em texto puro.

2. Redefinir senha de alguém

Envia ao e-mail um link para a pessoa criar uma senha nova (aluno ou diretor).

3. Modo manutenção

Quando ligado, os alunos veem uma tela de "em manutenção" e o banco recusa os acessos deles. A diretoria continua entrando. Status: ...

4. Restaurar backup

Escolha um arquivo gerado em "Baixar backup". Os dados são regravados por cima dos atuais (nada é apagado). O log de ações não é restaurado e as contas de login dos alunos não são recriadas.

🔄 Nova Gestão só você

Ferramentas de virada de gestão. Aparecem apenas para o e-mail raiz do sistema.

1. Trocar a diretoria

Uma linha por diretor: Nome;email;cargo;nivel;senha (nível: admin, membro ou marketing; a senha é opcional e só serve para criar a conta de login).

2. Backup da gestão

Baixa um arquivo com alunos (sem senhas), pautas, eventos, sugestões, materiais, jogos, enquetes, avisos, cargos e log. Faça isto antes da limpeza.

3. Limpeza para a nova gestão

Apaga de forma definitiva só o que você marcar. Os alunos não são mexidos.

4. Formandos / desativar turma

Digite o nome da turma exatamente como está no campo "turma" dos alunos. Todos os alunos dela serão bloqueados.

🧑‍💼 Diretoria e Cargos

Quem está aqui entra no painel. Níveis: admin (vê tudo), membro (materiais, eventos, jogos) e marketing (relatório, mural, enquetes). Para criar a conta de login, preencha a senha (6+ caracteres); se a pessoa já tem conta, deixe em branco.
