- [ ] Foi criado um **projeto Firebase exclusivo da escola**.
- [ ] As configurações públicas Web foram validadas **pelo processo técnico**.
- [ ] Authentication, Firestore e regras de segurança foram configurados.
- [ ] Foi provisionado um administrador inicial por procedimento seguro.
- [ ] Hospedagem/URL próprias estão preparadas.
- [ ] O Portal e o Admin usam o mesmo Firebase daquela escola.
- [ ] Os testes de isolamento com escolas fictícias foram aprovados.
- [ ] Os créditos originais aparecem e não são editáveis pelo painel.
- [ ] Há aprovação **explícita** para publicar.
- [ ] O backup/restauração e os custos foram revisados.
